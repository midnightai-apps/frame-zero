# Frame Zero

A photo and collage editor for macOS.

This repository contains official release downloads and update manifests only. Application source code is maintained separately.

## Download

Get the signed and notarized DMG from [Releases](https://github.com/midnightai-apps/frame-zero/releases). Requires Apple Silicon and macOS 14 or later.

Open the DMG and drag Frame Zero to Applications.
