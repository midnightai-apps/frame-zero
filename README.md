# Frame Zero

A photo and collage editor for macOS and Windows.

This repository contains official release downloads and update manifests only. Application source code is maintained separately.

## Download

Get the signed and notarized DMG from [Releases](https://github.com/midnightai-apps/frame-zero/releases). Requires Apple Silicon and macOS 14 or later.

Open the DMG and drag Frame Zero to Applications.

## Windows

[Download FrameZero.exe (Windows 0.1.1)](https://github.com/midnightai-apps/frame-zero/releases/download/windows-v0.1.1/FrameZero.exe). Windows 11 x64 and Microsoft Edge WebView2 Runtime are required. Run the EXE directly; no installer is needed.

The Windows edition supports image editing and PNG/JPEG/WebP export. Motion graphics, audio, timelines, and MP4 export are excluded.

The app checks for updates automatically. Choose **업데이트 후 다시 시작** to verify the signed download, save the project, replace the EXE, and reopen the project. Manual checks are available under **도움말 ▸ 업데이트 확인…**. Windows updates use the windows-stable/latest-windows.json channel; existing macOS releases and their update channel remain separate.
